# Raspberry Pi Monitor (`tempmon`)
Монитор температур `CPU` и `NVMe`, рассчитанная на `Raspberry Pi` с `Linux`.

---

## Возможности
- Температуры: `CPU` из `sysfs`; `NVMe` из `nvme smart-log`.
- NVMe SMART: `percentage_used`, `critical_warning`, название модели.
- Индикаторы температур с порогами, средняя системная нагрузка, обновление по таймеру.
- Клавиши выхода: `q`, `e`, `Esc`, `Ctrl+C`, `Ctrl+Z`.
- Отдельный слой датчиков и терминальный UI для последующего FastAPI.
- ⚠️`fans.py` __пока заглушка__: `RPM`/`PWM` выводятся как `н/д`.

---

## Требования
- `Raspberry Pi` / `Linux`
- `Python 3.10+`
- `nvme-cli`
- `sudo` при необходимости чтения SMART


## Файлы
| Файл              | Назначение                                                                           |
|-------------------|--------------------------------------------------------------------------------------|
| `monitor.py`      | аргументы запуска, главный цикл и сбор показаний                                     |
| `config.py`       | пороги температуры и интервал                                                        |
| `sensors/cpu.py`  | поиск термозоны и чтение температуры CPU                                             |
| `sensors/nvme.py` | NVMe обнаружение, sudo и разбор SMART                                                |
| `sensors/fans.py` | ⚠️ Интерфейсы вентиляторов, __без чтения реального `RPM`/`PWM`__                     |
| `ui/terminal.py`  | цвета, TTY, клавиши и вывод                                                          |
| `install.sh`      | установка и безопасная замена команды `tempmon`                                      |
| `uninstall.sh`    | Удаление установленного temp-monitor и команды tempmon с сохранением резервных копий |

---

## Запуск без установки
```bash
python3 monitor.py 1
```

---

## Установка (замена команды `tempmon`)
Из директории распакованного проекта:
```bash
chmod +x install.sh
./install.sh
```

Установщик копирует проект в `~/.local/share/temp-monitor/` 
и создаёт `/usr/local/bin/tempmon` через `sudo`. 

Если ранее существовал `/usr/local/bin/tempmon`, 
сохраняет его как `/usr/local/bin/tempmon.backup-ДАТА-ИД` перед заменой. 

Установка `nvme-cli`, если не установлен, идёт через `apt-get` и может запросить `sudo`.

### Проверка установки
После установки выполните:
```bash
command -v tempmon
tempmon --help
tempmon       # 1 секунда
tempmon 0.5   # 0.5 секунды
tempmon 1,5   # 1.5 секунды
```

## Удаление программы
Из директории распакованного проекта:
```bash
chmod +x uninstall.sh
./uninstall.sh
```

__Важно:__ запускайте скрипт от обычного пользователя, без `sudo`.   
При необходимости он самостоятельно запросит повышенные права.

### Что удаляется
| Компонент                       | Действие                                                      |
|---------------------------------|---------------------------------------------------------------|
| `/usr/local/bin/tempmon`        | __Удаляется__, если принадлежит установленному `temp-monitor` |
| `~/.local/share/temp-monitor/`  | __Удаляется__ каталог установленной программы                 |
| `~/temp-monitor/`               | Исходные файлы проекта __сохраняются__                        |
| `nvme-cli`                      | __Не удаляется__                                              |
| `tempmon.backup-*`              | Резервные копии __сохраняются__                               |

### Проверка удаления
После завершения выполните:
```bash
command -v tempmon
```
Если команда отсутствует в `PATH`, вывод будет пустым.

## Восстановление предыдущей версии
При установке `install.sh` создаёт резервную копию существующей команды `tempmon`.

Для поиска резервных копий:
```bash
ls -l /usr/local/bin/tempmon.backup-*
```

Для восстановления выберите нужную копию и выполните:
```bash
sudo cp -a /usr/local/bin/tempmon.backup-ДАТА-ИД /usr/local/bin/tempmon
```
Замените `ДАТА-ИД` фактическим суффиксом резервной копии.

__Примечание:__ `uninstall.sh` не восстанавливает предыдущую версию автоматически.   
Резервные копии сохраняются для ручного восстановления.

## Настройки
Для изменения настроек, внесите изменения в `config.py`, 
затем повторно выполните `./install.sh` (установка делает копию).  
__Интервал__ возможно также передать в виде аргумента. 

Установленный конфиг лежит в `~/.local/share/temp-monitor/config.py`.

По умолчанию:
- `CPU` предупреждение `70 °C` / критический `80 °C`; 
- `NVMe` предупреждение `60 °C` / критический `70 °C`.

---

## NVMe
Если у вас несколько `NVMe`, укажите контроллер:
```bash
NVME_CTRL=/dev/nvme1 tempmon
```

__SMART__ может потребовать права `root`. 
Монитор работает обычным пользователем, а для `NVMe` 
выполняет `sudo -v` и затем `sudo -n nvme smart-log`. 

При долгой непрерывной работе срок действия `sudo` может истечь 
и тогда SMART будет отображаться как `н/д`.

## Безопасность и ограничения
- Установщик меняет только файлы своей установленной копии и `/usr/local/bin/tempmon`
(с резервным копированием существующего файла). Перед запуском изучите `install.sh`.
- Если прежняя команда `tempmon` была в другом месте PATH, проверьте `type -a tempmon` и порядок путей.
- Для отката при наличии резервной копии, например: `sudo cp -a /usr/local/bin/tempmon.backup-... /usr/local/bin/tempmon`.
- ⚠️ Реальные `RPM`/`PWM` вентиляторов __не реализованы__ (_идет проверка GPIO/sysfs вариантов схем подключения_).
